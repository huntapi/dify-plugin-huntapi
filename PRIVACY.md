# Privacy policy

This plugin is published by HuntAPI (https://www.huntapi.com).

## What the plugin sends

When a tool runs, the plugin sends the URL of the video and the download options to the HuntAPI API at `https://api.huntapi.com`, with your API key in the `x-api-key` header. When you save the API key in Dify, the plugin checks it with one request that costs no credits.

The plugin calls no other host.

## What the plugin stores

The plugin stores nothing. It keeps no logs, files or caches. Dify stores the API key you enter, as it does for every plugin credential.

## What HuntAPI does with the data

HuntAPI processes requests to return results and to count credits on your account. See the HuntAPI privacy policy: https://www.huntapi.com/privacy
